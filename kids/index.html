어린이보호구역 및 유동인구
입체 분석 지도 서비스 (PRD)

공공 빅데이터를 활용하여 부산광역시 진구 관내 어린이보호구역 현황과 격자별 유동인구를 융합 분석합니다. CCTV 미설치 지역 및 유동인구 밀집 사각지대를 직관적으로 시각화하여 안전 대책 수립을 지원하는 웹 서비스입니다.

분석 대상 보호구역

74 개소

유동인구 분석 격자

60 개 구역

CCTV 설치 상태

Y / N 범례구분

시각화 엔진

Leaflet .js

01

프로젝트 개요 및 데이터 범위

어린이보호구역 데이터

jingu_data.js / jingu_data.json

전국어린이보호구역표준데이터.csv 원본 데이터에서 부산광역시 진구 관내 총 **74개** 시설을 추출하여 정제하였습니다.

  • 유치원, 초등학교, 어린이집 등 시설 종류 구분
  • 소재지 도로명/지번 주소 및 관할 경찰서 표기
  • CCTV 설치 여부 및 설치 대수 정보 포함

유동인구 분석 데이터

population_data.js / population_data.json

부산진구 유동인구분석_2026-08-04.csv 데이터를 가공하여 **60개 격자 구역**의 공간 범위와 유동인구수를 매핑하였습니다.

  • 격자별 위·경도 바운딩 박스(Grid Bounds) 정의
  • 구역별 시간/일간 평균 유동인구 수치 연동
  • 인근 보호구역과의 연관 유동인구 추정 지표 제공
02

주요 기능 및 시각화 명세 (Visualizer)

보호구역 마커 구분

Leaflet Marker

CCTV 설치 여부에 따라 시각적 마커 색상을 완전히 이원화하여 한눈에 식별 가능하도록 구성합니다.

파란색 마커 (Blue)
CCTV 설치 (Y)
빨간색 마커 (Red)
CCTV 미설치 (N)

유동인구 히트맵 격자

Grid Overlay

60개 격자의 유동인구 밀도에 따라 가시성 높은 그라데이션 오버레이를 타일형으로 지도 위에 표시합니다.

낮음 (보라색) 보통 (주황색) 밀집 (빨간색)

* 사이드바 토글 버튼으로 히트맵 레이어를 자유롭게 On/Off 할 수 있습니다.

필터링 & 통계 요약

Control Panel
  • 시설종류 필터: 전체 / 유치원 / 초등학교 / 어린이집
  • CCTV 필터: 전체 / 설치(Y) / 미설치(N)
  • 안전 취약지구 하이라이트: 유동인구 高 + CCTV 미설치 사각지대 자동 감지
  • 검색: 시설명 키워드 검색 시 해당 마커 자동 이동 & 팝업

시스템 아키텍처 및 디렉토리 구조

AIkid2026 파일 구조 명세 

AIkid2026/
├── 전국어린이보호구역표준데이터.csv      (원본 보호구역 데이터)
├── 부산진구 유동인구분석_2026-08-04.csv (원본 유동인구 데이터)
├── jingu_data.json                      (보호구역 정제 JSON)
├── jingu_data.js                        (웹 로드용 보호구역 JS)
├── population_data.json                 (유동인구 정제 JSON)
├── population_data.js                   (웹 로드용 유동인구 JS)
├── PRD.md                               (요구사항 정의서)
├── index.html                           (메인 지도 앱 HTML)
├── style.css                            (다크 글래스모피즘 CSS)
└── app.js                               (Leaflet 지도 컨트롤)
마커 팝업 필수 표기 항목

마커 클릭 시 팝업에 **대상시설명**, **주소(도로명/지번)**, **보호구역 도로폭**, **관할경찰서명**, **CCTV 설치대수**, **인근 유동인구 추정 수치**가 실시간으로 연동되어 표시됩니다.

디자인 컨셉 (UI/UX)

Modern Dark Glassmorphic Dashboard 테마 적용으로 차분한 야간/관제 스타일 디자인을 유지하며 가독성을 최우선으로 확보합니다.

04

검증 및 테스트 계획 (QA)

1. 데이터 전구역 검증

74개 어린이보호구역 데이터 및 60개 유동인구 격자 데이터 좌표 누락 여부 전수 검증

2. 필터 & 레이어 인터랙션

시설/CCTV 필터링과 유동인구 히트맵 레이어 토글이 동시 작동할 때 렌더링 성능 검증

3. 팝업 데이터 정밀도

보호구역 및 격자 오버레이 클릭 시 팝업 내 항목(도로폭, 관할경찰서 등) 정상 인출 확인
