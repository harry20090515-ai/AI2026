# 🛡️ 부산진구 어린이보호구역 및 유동인구 입체 분석 지도 서비스
> **서비스 설명서 및 기획 명세서 (Service Overview & Specification)**

---

## 1. 📌 서비스 개요 (Overview)

본 서비스는 **부산광역시 진구** 내 어린이보호구역(74개소)의 CCTV 설치 현황 데이터와 60개 격자 구역의 유동인구 분석 데이터를 융합·시각화하는 **입체적 인터랙티브 웹 대시보드**입니다.

### 🌟 배경 및 목적
* **어린이 교통안전 사각지대 발굴**: 단순 보호구역 지정을 넘어, 실제 유동인구가 밀집하는 지역 중 CCTV가 설치되지 않은 **고위험 사각지대**를 직관적으로 분석합니다.
* **데이터 기반의 정책 의사결정 지원**: 구청, 경찰서 등 관계 기관이 CCTV 보강, 스쿨존 보차도 분리 등 안전 시설물 우선 투자 지역을 합리적으로 선정할 수 있도록 도웁니다.
* **지역 주민 정보 제공**: 학부모와 지역 주민이 자녀 통학로 주변의 안전 요소 및 유동인구 현황을 투명하게 확인하게 합니다.

## 3. 🖥️ 화면 레이아웃 및 UX 구성 (Layout & User Interface)

서비스 화면은 **현대적인 다크 글래스모피즘(Dark Glassmorphic) 스타일 대시보드** 형태를 취하며, 전체 스크린을 2개 메인 영역(사이드바 / 지도)으로 나눕니다.

```
+-----------------------------------------------------------------------------------+
|  🛡️ 부산진구 어린이보호구역 입체 분석 대시보드                          [통계 요약]  |
+------------------------------+----------------------------------------------------+
| 🔍 검색 및 스마트 필터        | 🗺️ 인터랙티브 지도 영역 (Interactive Map Canvas)   |
|  - 시설명 키워드 검색         |                                                    |
|  - 시설종류 (초등/유치원/어린이집) |   [🔵 CCTV 설치 마커]   [🔴 CCTV 미설치 마커]       |
|  - CCTV 여부 (전체/Y/N)      |                                                    |
|  - 유동인구 레이어 On/Off    |   [🟣~🟧~🔴 유동인구 히트맵 격자 오버레이]           |
|                              |                                                    |
| 📊 실시간 요약 통계 Card     |   [📌 마커/격자 클릭 시 상세 정보 팝업]             |
|  - 총 보호구역: 74개소        |    • 시설명 / 도로명주소                          |
|  - CCTV 설치율: XX%          |    • 보호구역 도로폭 / 관할경찰서                 |
|  - 🚨 고위험 사각지대: N개소  |    • 인근 유동인구 추정 수치                      |
|                              |                                                    |
| 📋 시설 목록 (List View)     |                                                    |
|  - (클릭 시 지도 이동 & 팝업) |                                                    |
+------------------------------+----------------------------------------------------+
```

### 3.1 메인 요소 상세 명세

1. **상단 컨트롤 & 브랜딩 (Top Header)**
   - 대시보드 타이틀 및 핵심 아이콘 표시
   - 전체 관내 총 유동인구 및 보호구역 종합 현황요약 칩(Chip) 구성

2. **좌측 분석 사이드바 (Left Dashboard Sidebar)**
   - **키워드 검색창**: 시설명(예: "벽산유치원", "성지초등학교") 입력 시 실시간 필터링
   - **다중 드롭다운 필터**:
     - 시설종류: `전체` | `초등학교` | `유치원` | `어린이집`
     - CCTV 설치여부: `전체` | `설치 (Y)` | `미설치 (N)`
   - **레이어 컨트롤 스위치**: 유동인구 히트맵 오버레이 켜기/끄기
   - **안전 지표 분석 카드 (Security Analytics Card)**:
     - 관내 총 보호구역 수 및 설치율
     - **🚨 안전 사각지대 (Safety Blindspot)**: 유동인구 상위 30% 영역 내 CCTV 미설치 시설 개수 하이라이트
   - **시설 인터랙티브 리스트**: 필터링된 결과 리스트 (클릭 시 해당 위치로 지도 카메라이동 및 팝업 표시)

3. **중앙 Leaflet 지도 영역 (Center Interactive Map)**
   - **어린이보호구역 마커**:
     - 🔵 **파란색 핀 (Blue Marker)**: CCTV가 설치된 안전 구역 (`CCTV설치여부 = Y`)
     - 🔴 **빨간색 핀 (Red Marker)**: CCTV가 미설치된 관심/개선 구역 (`CCTV설치여부 = N`)
   - **유동인구 히트맵 & 그리드 오버레이**:
     - 60개 위·경도 바운딩 박스를 유동인구 수치에 따라 반투명 컬러 스펙트럼(보라 → 주황 → 빨강)으로 표시
     - 그리드 클릭 시 구역 ID 및 정밀 유동인구수(명) 팝업 안내
   - **보호구역 상세 팝업 (Marker Popup Window)**:
     - **시설 정보**: 대상시설명, 시설종류, 소재지 도로명/지번 주소
     - **도로 및 관할**: 도로폭 정보, 담당 경찰서(부산진경찰서)
     - **CCTV 및 유동인구**: CCTV 설치대수 태그 및 인근 격자 유동인구 연동 수치

## 4. 📊 데이터 구조 및 연동 명세 (Data Specification)

본 서비스는 원본 데이터셋을 정제한 두 개의 경량 JS/JSON 데이터 모듈을 활용합니다.

```
[전국어린이보호구역표준데이터.csv]  ──(부산진구 74개 시설 추출)──> [jingu_data.js]
[부산진구 유동인구분석.csv]        ──(60개 격자 바운딩박스 추출)─> [population_data.js]
                                                                        │
                                                                        ▼
                                                       [입체 분석 웹 대시보드]
```

### 4.1 데이터 필드 명세
1. **`jingu_data.js` (어린이보호구역 데이터 - 74건)**
   - `시설명`: 보호구역 지정 시설 이름
   - `시설종류`: 초등학교, 유치원, 어린이집 등
   - `위도/경도`: Leaflet 지도 핀 좌표
   - `CCTV설치여부`: 'Y' 또는 'N'
   - `CCTV설치대수`: 설치 대수 (숫자)
   - `소재지도로명주소` / `소재지지번주소`
   - `보호구역도로폭`: 스쿨존 도로 폭 정보
   - `관할경찰서명`: 관할 경찰서

2. **`population_data.js` (유동인구 데이터 - 60건)**
   - `grid_id`: 격자 구역 식별자
   - `bounds`: `[[south, west], [north, east]]` 위·경도 영역 좌표
   - `population`: 해당 격자의 일평균/특정 시점 유동인구 수(명)

## 5. 💡 핵심 분석 포인트 및 정책 활용 방안 (Insights & Value)

1. **위험 입체 도출 (Risk Cross-Analysis)**
   - 유동인구가 매우 높은 격자(Red Zone) 내에 위치하면서 `CCTV설치여부 = 'N'`인 초등학교/유치원을 자동 추출하여 우선 개선 대상으로 지정합니다.
2. **시각적 직관성 (Visual Intuition)**
   - 지도 위에서 빨간색 마커(CCTV 미설치)와 주황/빨간색 유동인구 레이어가 겹치는 지점이 곧 **최우선 CCTV 보강 구역**임을 직관적으로 보여줍니다.
3. **확장 가능성 (Scalability)**
   - 향후 신호등 설치 여부, 어린이 교통사고 발생 이력 데이터, 스쿨존 속도제한 데이터 등을 추가 레이어로 용이하게 확장이 가능합니다.
